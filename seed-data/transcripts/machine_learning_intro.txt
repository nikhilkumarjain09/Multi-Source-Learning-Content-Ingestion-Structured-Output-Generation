# Introduction to Machine Learning

Machine Learning is a branch of artificial intelligence focused on building applications that learn from data and improve their accuracy over time without being explicitly programmed.

## Supervised Learning
Supervised Learning is a category of machine learning where algorithms are trained on labeled datasets. The algorithm learns a mapping function from input variables to output variables.

### Linear Regression
Linear Regression is a fundamental supervised learning algorithm used to predict continuous numerical values by fitting a linear equation to observed data points.

## Unsupervised Learning
Unsupervised Learning involves training models on unlabeled data. The goal is to discover underlying patterns, groupings, or representations within the dataset.

### Clustering
Clustering algorithms group data points with similar characteristics into distinct clusters without prior training labels.
